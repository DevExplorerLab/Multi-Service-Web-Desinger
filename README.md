💰 Fiyatlandırma

Kullanıcıların hizmet seçerek il ve ilçe bilgilerine göre fiyatlandırma detaylarını görüntüleyebildiği bir sistem tasarlanmıştır.

Bazı hizmetlerde sabit başlangıç fiyatları, bazı hizmetlerde ise WhatsApp üzerinden teklif alma sistemi bulunmaktadır.
